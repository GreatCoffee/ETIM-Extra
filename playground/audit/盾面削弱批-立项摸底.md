### 2.2 M-2 · 接口签名草案（含 M-2a 取整真裁点）

**建议签名（双方法，均携带 `DamageSource`；**已裁 D-5：签名冻结，方法名不得再改**）**

```java
public interface ETIMShield {
    float getBlockReduction(DamageSource source);   // 0.0 ~ 1.0，被挡掉的**比例**
    float getWearMultiplier(DamageSource source);   // ≥ 0.0，磨率**乘子**（基准率在 config）
}
```

> **命名已裁（D-5）**：`getBlockReduction` / `getWearMultiplier`（不是 `blockReduction` / `etimBlockReduction`）。下文凡出现旧写法一律按此读；§6.1 伪代码已同步。

| 判点 | 判值 / 依据 | path:line |
|---|---|---|
| ① 为什么必须带 `DamageSource` | 银盾两面（幽魂 / 非幽魂）**只能**由来源区分；不带 source 则银盾只能取单值，§一.4 的 3.5 / 1.25 双磨率无处落 | — （设计要求，`shield-design-复盘.md:175` 同旨） |
| ② 语义是「减伤比例」还是「保留系数」 | **命名陷阱**：现行 `blockDamageFactor` 是**保留系数**（0.5 = 留一半）；接口取**减伤比例**（0.5 = 挡掉一半）。木盾两者数值巧合相等（1 − 0.5 = 0.5），故 `blocked = max(raw × (1 − r), floor)` 在木盾上**逐位不变** | 现行 `combat\ETIMBlocking.java:125-126`；木盾 0.5 见 `shield-design-复盘.md:150` |
| ③ default 实现 | 木盾缺省值 **0.5 / 1.0**（= §一.1 木盾 50%，= 现行 ÷2 的保留系数 0.5） | `combat\ETIMBlocking.java:125`、`:144` |
| ④ 乘子而非绝对率 | `wearMultiplier` 返回 1.0（木/铜/远古/秘银/艾德曼）/ 1.4（银·非幽魂）/ 0.5（银·幽魂），基准率 2.5 在 config ⇒ **银两面 = 2.5×1.4 = 3.5 / 2.5×0.5 = 1.25** 与 §一.4 逐位一致 | `ETIMConfig.java:367-369`（现行单率形态） |
| ⑤ 冻结纪律 | 签名发布即 API；变更走主账本 + 通知附属（依赖口径第四条） | `audit20-裁定回执.md` 条 114；溯 `extra-shield-削弱批-知会回执.md:20-22`（§四「同一次 publishToMavenLocal 里发 dev jar」） |

**M-2a（磨损返回值 float vs int）——本件的一手结论**

| 事实 | 数据 | 依据 |
|---|---|---|
| F1 终账 21 格**本身就按 `(int)` 截断算出来** | 用 `wear = (int)(挡后值 × 2.5 × 乘子)` 复现：**L0 21/21 命中**（§三表） | 本件 §三 + JVM 实测 |
| F2 不变量在 `(int)` 下**破裂** | 银·幽魂 8 伤 = 533 击 vs 远古 8 伤 = 457 击（**+16.6%**）；L3 面 969 vs 832 | 终裁表 `shield-design-复盘.md:231-232`；本件 §三 |
| F3 浮点会让终账**全表作废** | 凡 wear 非整数的格全变（12 格）；且需为余量引入状态（NBT 小数记账）才能严格闭合 | 本件 §三 |
| **结论（一手建议）** | **签名返回 float（API 冻结面取宽），落地仍 `(int)` 截断（保 21 格终账）**。不变量按「已破」登记（B-6），设计措辞由「等效耐久 = 远古盾」改为「银盾幽魂面 ≈ 远古盾（+17% 击数）」。未来若确需严格闭合，只改落地算术，**不必改接口** | — |

> 为什么不是「先 int 以后再说」：`ETIMShield` 是**对外发布的 API**（附属编译期依赖），签名一旦发布再改 float 就要走冻结纪律 + 双侧重编；返回 float 而内部按 int 用，成本为零、后路全留。这正是项目约束 7（架构决策往长了做）的直接应用。

### 2.3 M-3 · 分发口三支（改点唯一：`onLivingHurt` + `wearShieldOrTool`）

| 支 | 命中条件 | 取值 | 现行对照 | 状态 |
|---|---|---|---|---|
| **①** 接口支 | `active.getItem() instanceof ETIMShield` | `r = shield.blockReduction(source)`；`m = shield.wearMultiplier(source)`；`blocked = max(raw × (1 − r), blockMinDamage)`；`wear = (int)(blocked × baseRate × m)` | 现行无此支 | **新增** |
| **②** 原版木盾支 | `active.getItem() instanceof net.minecraft.item.ItemShield` | 常量 0.5 / 1.0 → `blocked = max(raw × 0.5, 1.0)`（= 现行逐位） | 现行盾支（走 `isShield` 布尔，无值） | **等价替换** |
| **③** 其余 | 工具/武器（`isBlockCarrier` 的 11 个 exact class） | 现行一字不动：`blocked = max(raw × blockDamageFactor, blockMinDamage)`；`wear = (int)(blocked × decay)`（剑 decay = 50） | `combat\ETIMBlocking.java:125-126`、`:145-147` | **零改动** |

**分支次序硬约束**：**① 必须先于 ② 判定**。理由：附属五盾 `isShield()` 已返回 true（`shield\ETIMExtraItemShield.java:91-94`），若先判 `isShield` 再判接口，附属会被木盾常量吃掉（55% 的铜盾变 50%）。`instanceof ETIMShield` 与 `instanceof ItemShield` 在类型上互斥（附属盾 extends `Item`，不继承 `ItemShield`，见上批 L-3 六条负担），但仍须**显式排序**并在注释写明。

**现行判据面的连带**：`isBlockingCarrier` 现为 `isBlockCarrier(stack) || isShieldStack(stack)`（`:100-102`）。接口支不改这个门（附属盾经 `isShield=true` 已进），但建议追加 `|| stack.getItem() instanceof ETIMShield` 作**第三重保险**（万一附属某件忘了覆写 `isShield`，仍能被分发）——成本一行，收益是「注册成功但白板」这类静默故障消失。

**`isShield` 是否继续返回 true**：**是**。它承载的不是格挡值，而是 1.12 的四条外围语义：附魔台可附（`item\Item.java:1169-1172` 走 `isDamageable`，不经 `isShield`，但 `ItemShield` 语义面仍建议保持）、铁砧、`StatList` 破盾统计（`item\ItemStack.java:399`）、副手槽自动选择（`entity\EntityLiving.java:1130`）。拔掉它只会砸掉外围，不换任何减伤。

### 2.7 M-7 · 值面核讫（终账 21 格逐格复核 + 取整 + 浮点边界）

package io.github.etim.etim.combat;

import net.minecraft.util.DamageSource;

/**
 * 盾的**数值契约**（盾面削弱批 M-1/M-2）。本体只持"怎么算"，附属持"值多少"。

 * <p>The numeric contract of a shield. The main mod owns "how to compute",
 * the add-on owns "how much". Both methods take the source because the silver

 * apart. Published signature = frozen API.</p>
 */
public interface ETIMShield {

    /** 被挡掉的比例 0..1（NOT the retained factor — 与 {@code blockDamageFactor} 相反）。

    default float getBlockReduction(DamageSource source) {

    }

    /** 磨率乘子（≥0；基准率在 config，木盾 = 1.0）。Wear-rate multiplier; the base rate lives in config. */
    default float getWearMultiplier(DamageSource source) {
        return 1.0F;                                    // M-2③: 木盾缺省 1.0
    }
}
