### 2.2 M-2 · 否定率公式（L3 核心判值）

| 项 | 内容 |
|---|---|
| R196 一手 | `EnchantmentHelper.java:43-49`：`return hasLevels() ? (float)level / getNumLevels() : 1.0F`；`ItemStack.java:276`：`chance_of_negation_per_point = fraction_of_unbreaking * 0.75F`；L3 = 3 ÷ 5 × 0.75 = **0.45** |
| 1.12.2 落法 | `enchantment\EnchantmentDurability.java:53-63`：`:55-58` 只有 `ItemArmor` 走 0.6 定值；`:61` 其余 `rand.nextInt(level + 1) > 0` ⇒ L3 = 3/4 = **0.75** |
| 期望磨损倍率 | R196 面 `1 − 0.45 = 0.55`（×1.818 击）；vanilla 面 `1 − 0.75 = 0.25`（×4 击）——**同一「L3」标签差 2.2 倍** |
| 判行锚 | §三 的 N 击聚合表（两个模型的 ±3σ 窗互不重叠，见 §3.1 末列） |

```java
// 伪代码 A（现状，零改动）：1.12 vanilla
negateDamage(stack, level, rand):
  if (stack.item instanceof ItemArmor && rand.nextFloat() < 0.6F) return false
  return rand.nextInt(level + 1) > 0          // L3 => 0.75

// 伪代码 B（若裁 R196 面）：单点覆写，别在 wear 计算里另开一套
negateDamage(stack, level, rand):
  float fraction = (float) level / 5.0F       // R196 EnchantmentHelper:47，分母 5
  return rand.nextFloat() < fraction * 0.75F  // R196 ItemStack:276-279 的等价重写
```

**核讫结论**：两式**不等价**，差的是「分母」（5 vs level+1）。伪代码 B 的 `level / 5` 直接照抄 R196 分母，故 L3 落 0.45；若想保留 R196 的 L5 = 0.75，必须同时接受「1.12 侧最大 3 级」→ 上不去（M-3）。
